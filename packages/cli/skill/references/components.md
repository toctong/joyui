# JoyUI component catalog

Docs app demonstrates JoyUI sources under `apps/docs`. Prefer the JoyUI CLI/MCP for app projects.

## Docs sections

| Section | Route | Install examples |
|---------|-------|------------------|
| 快速入门 | `/docs` | `npx @joyui/cli@latest init` |
| 基础规范 | `/docs/color` `/docs/typography` | theme · typography · globals |
| 基础组件 | `/docs/base` | `button` `input` `select` `modal` … |
| 组合组件 | `/docs/compounds` | `composer-loader` `auth-card` … |
| 图表 | `/docs/charts` | `stat-cards` `revenue-chart-card` `orders-chart-card` |
| 模板 | `/docs/templates` | `chat-starter` and Pro templates |

## JoyUI registry (npm package)

| Name | Layer | Install |
|------|-------|---------|
| utils | lib | `npx @joyui/cli add utils --yes` |
| format | lib | `npx @joyui/cli add format --yes` |
