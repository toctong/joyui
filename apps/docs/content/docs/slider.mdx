水平滑块。`Slider` 单值，`RangeSlider` 区间。下方是**同一个** 滑块家族的不同配置。

<ComponentDocPreview slug="slider" />

## 安装

```bash
npx @joyui/cli add slider --yes
```

或通过 JoyUI MCP / CLI 安装。

## 单值

`label`、`thumbLabel`；`showTooltip={false}` 可关闭气泡。

<DemoFrame
  fileName="slider-value.tsx"
  code={`import { Slider } from "@/components/base/slider/slider";

<>
  <Slider label="音量" defaultValue={40} thumbLabel="音量" />
  <Slider label="不显示气泡" defaultValue={25} showTooltip={false} thumbLabel="不透明度" />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <SliderValuePreview />
</DemoFrame>

## 区间

`RangeSlider` + `thumbLabels` + `formatValue`。

<DemoFrame
  fileName="slider-range.tsx"
  code={`import { RangeSlider } from "@/components/base/slider/slider";

<RangeSlider
  label="价格区间"
  defaultValue={[20, 80]}
  thumbLabels={["最低价", "最高价"]}
  formatValue={(v) => \`¥\${v}\`}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <SliderRangePreview />
</DemoFrame>

## 应用场景

筛选面板：预算区间。

<DemoFrame
  fileName="slider-filter.tsx"

<RangeSlider

  minValue={0}
  maxValue={100}

  formatValue={(v) => \`¥\${v * 10}\`}
/>`}
