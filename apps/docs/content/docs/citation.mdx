<ComponentDocPreview slug="citation" />

## 安装

```bash
npx @joyui/cli add citation --yes
```

或通过 JoyUI MCP / CLI 安装。

## 链接与图标

`index` 序号；`href` 外链；`showIcon={false}` 隐藏图标。

<DemoFrame
  fileName="citation-links.tsx"

</>`}
