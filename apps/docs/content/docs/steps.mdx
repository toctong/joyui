用 `current`（从 0 起）标记当前步，已完成步骤显示勾选。

<ComponentDocPreview slug="steps" />

## 安装

```bash
npx @joyui/cli add steps --yes
```

```tsx
import { Steps } from "@joyui/react";

<Steps
  current={1}
  steps={[
    { title: "Account", description: "Cookie" },
    { title: "Sources", description: "TMDB" },
    { title: "Done" },
  ]}
/>
```
