一套步骤家族：基础 `Steps` 用 `current`（从 0 起）标记进度；需要内容面板与上一步 / 下一步时换用下方向导变体。

## 基础步骤条

已完成步骤显示勾选；支持 `orientation="horizontal" | "vertical"`。

<ComponentDocPreview slug="steps" />

```bash
npx @joyui/cli add steps --yes
```

### 横向

默认方向，适合页面顶栏与弹窗向导头。

<DemoFrame
  fileName="steps-horizontal.tsx"
  code={`import { Steps } from "@/components/base/steps/steps";

<Steps
  current={1}
  orientation="horizontal"
  className="w-full max-w-xl"
  steps={[
    { title: "账号", description: "Cookie" },
    { title: "片源", description: "TMDB" },
    { title: "完成", description: "确认" },
  ]}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <StepsHorizontalPreview />
</DemoFrame>
