一套光斑卡家族：基础指针跟随；需要更强表现力时换倾斜或边框光束变体，API 各自独立、安装按 slug。

## 基础

Bencho 式微交互：不改内容结构，只加一层可跟随的光斑。

<ComponentDocPreview slug="spotlight-card" />

```bash
npx @joyui/cli add spotlight-card --yes
```

## 3D 倾斜

指针驱动的轻微透视倾斜 + 同款光斑；幅度克制（默认 ≤7°），尊重减少动态。

<ComponentDocPreview slug="spotlight-card-tilt" />

```bash
npx @joyui/cli add spotlight-card-tilt --yes
```
