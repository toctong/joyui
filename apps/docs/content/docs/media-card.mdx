一套媒体卡家族：基础海报网格；需要悬停揭示或剧集横排时直接换下方变体，API 各自独立、安装按 slug。

## 基础

TMDB / 豆瓣发现网格的标准封面卡。无 `src` 时显示占位面。封面底部叠加内容用 `footer`（评分条、进度），不要做漂浮角标。

<ComponentDocPreview slug="media-card" />

```bash
npx @joyui/cli add media-card --yes
```

## 悬停揭示

封面微缩放，底部叠加与下方操作在悬停 / 聚焦时滑入；适合发现网格想多露一点信息又不挤标题区的场景。

<ComponentDocPreview slug="media-card-hover" />

```bash
npx @joyui/cli add media-card-hover --yes
```
