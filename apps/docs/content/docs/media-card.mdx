TMDB / 豆瓣发现网格的标准封面卡。无 `src` 时显示占位面。

<ComponentDocPreview slug="media-card" />

## 安装

```bash
npx @joyui/cli add media-card --yes
```

整库：

```tsx
import { Button, MediaCard } from "@joyui/react";

<MediaCard
  title="Severance"
  subtitle="2022 · TV"
  src="https://image.tmdb.org/t/p/w342/…"
  action={<Button size="small" variant="secondary">Add task</Button>}
/>
```

## 应用场景

Discovery 热榜网格：`title` + 评分 `subtitle` + 「创建任务」`action`。  
封面底部叠加内容用 `footer`（评分条、进度），不要做漂浮角标。

图片默认 `referrerPolicy="no-referrer"`，方便外链海报。
