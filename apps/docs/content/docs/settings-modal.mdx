多页设置对话框：通用、资料、工具与存储。受控 `isOpen` / `onClose`；可用 `defaultPage` 指定打开页。

<ComponentDocPreview slug="settings-modal" />

## 安装

```bash
npx @joyui/cli add settings-modal --yes
```

或通过 JoyUI MCP / CLI 安装。

## 打开到通用

宿主按钮控制 `isOpen`；默认页 `general`。

<DemoFrame
  fileName="settings-modal-general.tsx"
  code={`import { useState } from "react";
import { Button } from "@/components/base/buttons/button";
import { SettingsModal } from "@/components/application/settings/settings-modal";

function Example() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button onClick={() => setOpen(true)}>打开设置 · 通用</Button>
      <SettingsModal
        isOpen={open}
        onClose={() => setOpen(false)}
        defaultPage="general"
        planArtSrc="/templates/settings-plan-art.png"
      />
    </>
  );
}`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <SettingsModalGeneralPreview />
</DemoFrame>
