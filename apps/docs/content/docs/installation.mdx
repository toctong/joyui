参考 [shadcn/ui Installation](https://ui.shadcn.com/docs/installation) 与 [Monorepo](https://ui.shadcn.com/docs/monorepo) 的「按起点选路径」思路：JoyUI 的**默认路径是整库 npm**（样式已打进包），CLI / Registry 只是可选的源码拷贝。本仓库自身也按 monorepo 布局：`packages/ui` 为权威组件包，`apps/docs` 为文档应用。

## 推荐：整库 npm

适合新项目和绝大多数业务应用。

```bash
pnpm add @joyui/react
# npm i @joyui/react / yarn add @joyui/react / bun add @joyui/react
```

只需安装 `@joyui/react`。表格、图表、图标、动画、日期、二维码、条形码、Composer（TipTap）等运行时依赖已作为包内 **dependencies** 随库安装。

宿主应用仍需自己准备：

- `react` / `react-dom`（peer）
- `tailwindcss` v4（样式构建）

### 1. 引入内置样式

在全局 CSS 中：

```css
@import "tailwindcss";
@import "@joyui/react/styles.css";
```

或在入口 JS：

```ts
import "@joyui/react/styles.css";
```

`styles.css` 内含：

- 设计 token（`theme.css`）
- 复合字阶（`typography.css`）
- 组件专用规则（表格 / Skeleton / AgentThinking / 图表动画等）
- `@source` 扫描包内 `dist`，无需再手写 Tailwind content 路径

### 2. Provider + 使用

```tsx
import { JoyUIProvider, Button, Input, RevenueChartCard } from "@joyui/react";

export function App() {
  return (
    <JoyUIProvider locale="zh-CN">
      <Button variant="primary">保存</Button>
      <Input label="邮箱" placeholder="you@company.com" />
      <RevenueChartCard />
    </JoyUIProvider>
  );
}
```

AI 套件（`AiChat` / `useChat`）已内置在主入口；`ai` 与 `@ai-sdk/react` 随包安装。TipTap Composer 仍走子路径：

```tsx
import { AiChat, useChat } from "@joyui/react";
import { Composer, ComposerPanel } from "@joyui/react/composer";
```

详见 [AI](/docs/ai)。

### 3. 一键初始化（可选）

写入 `styles/joyui.css`、`components.json`、Cursor rules、`AGENTS.md`：

```bash
npx @joyui/cli@latest init --yes
```

### 应用自己还要装什么？

| 场景 | 是否额外安装 |
|------|----------------|
| 只用 JoyUI 组件（含 AiChat / useChat） | 否 |
| TipTap 胶囊 Composer | 是：TipTap peers（见 Composer 文档） |
| 业务代码里 `import { RiXxx } from "@remixicon/react"` | 是（图标给**你的**页面用） |
| `@tanstack/react-query`、路由、axios 等业务库 | 是（与 JoyUI 无关） |

## 设计约定

- 语义 token：`text-text-primary`、`bg-background-primary-default`、`border-border-default`
- 字阶：`text-title-2-medium`、`text-body-1-regular`（不要拆成 `text-sm font-medium`）
- 合并 class：`cx()` / `cn()`（来自 `@joyui/react`）
- 图标：`@remixicon/react` 传**组件引用**，不是 `<Icon />`
- 按钮禁用：`disabled` 与 `isDisabled` 均可
- 深色：`.dark` 翻转 token，禁止手写 `dark:` 调色板

> 带 `label` / `placeholder` / `hint` 的字段请用 **`Input`**（或 `Textarea`）。`TextField` 是 React Aria 组合容器，不接受这些 props。  
> 业务表格用 **`DataTable`**（传入 `data` / `columns`）；`DataTableExample` 仅是文档演示。

## 可选：CLI 拷贝源码（shadcn 风格）

需要把单个组件源码写进业务仓库再改时：

```bash
npx @joyui/cli@latest init --yes
npx @joyui/cli add button data-table --yes
```

或配置 shadcn registry 后：

```bash
npx shadcn@latest add @joyui/button
```

`components.json` 示例（`joyui init` 会写入）：

```json
{
  "registries": {
    "@joyui": "https://joyui.dev/r/{name}.json"
  }
}
```

整库使用仍优先 `pnpm add @joyui/react`。
