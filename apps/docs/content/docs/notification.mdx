## 安装

```bash
npx @joyui/cli add notification --yes
```

或通过 JoyUI MCP / CLI 安装。


## 应用场景

将上方预览中的 props 换成业务文案与状态即可用于表单、工具栏或设置页。

上方预览中的文案、选项与数据均可替换为业务配置；不要复制写死的演示常量到生产。
