通知家族：单条 `Notification`，以及分组收件箱 `NotificationCenter`。

## 通知

带状态图标、头像、操作与倒计时的通知。

<ComponentDocPreview slug="notification" />

```bash
npx @joyui/cli add notification --yes
```

### 状态

`status`：`information` · `success` · `error` · `neutral`。

<DemoFrame
  fileName="notification-status.tsx"
  code={`import { Notification } from "@/components/base/notification/notification";

  <Notification status="success" title="转存完成" description="《星际穿越》已写入目标目录。" timestamp="2 分钟前" dismissible={false} />

### 头像与操作

`avatar` 优先于状态图标；`actions` 渲染在正文下方。

<DemoFrame
  fileName="notification-actions.tsx"
  code={`import { Notification } from "@/components/base/notification/notification";

<div className="flex w-full max-w-md flex-col gap-3">
  <Notification
    status="neutral"
    title="林晓 评论了你的任务"
    description="命名规则可以再紧一点。"
    timestamp="10 分钟前"
    avatar={{ initials: "林", color: "lime" }}
    actions={[
      { label: "查看", variant: "secondary" },
      { label: "忽略", variant: "ghost" },
    ]}
    dismissible={false}
  />
  <Notification
    status="error"
    title="磁盘空间不足"
    description="剩余不足 5 GB，部分任务已暂停。"
    timestamp="刚刚"
    actions={[{ label: "清理空间", variant: "primary" }]}
    dismissible={false}
  />
</div>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-secondary-default p-8"
>
  <NotificationActionPreview />
</DemoFrame>
