为按钮或卡片叠加材质涟漪；`text-*` 类决定波纹颜色。

<ComponentDocPreview slug="ripple" />

## 安装

```bash
npx @joyui/cli add ripple --yes
```

## 色调与关闭

`disabled` 关闭涟漪，保留子节点。

<DemoFrame
  fileName="ripple-tones.tsx"
  code={`import { Button } from "@/components/base/buttons/button";
import { Ripple } from "@/components/base/ripple/ripple";

<>
  <Ripple className="rounded-2lg text-accent-500"><Button>主色涟漪</Button></Ripple>
  <Ripple disabled className="rounded-2lg text-accent-500"><Button variant="ghost">关闭</Button></Ripple>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"

</DemoFrame>
