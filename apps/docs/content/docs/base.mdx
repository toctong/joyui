日常搭建界面用的基础积木：表单、反馈、导航与浮层。安装示例：

```bash
pnpm add @joyui/react
```

```tsx
import { /* … */ } from "@joyui/react";
```

主题 CSS 已内置：`@import "@joyui/react/styles.css"`。可选：`npx @joyui/cli add button input select modal --yes`。
