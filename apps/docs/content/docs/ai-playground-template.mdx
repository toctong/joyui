## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AiPlaygroundTemplate } from "@joyui/react";

<AiPlaygroundTemplate
  className="h-[640px]"
  onRun={async (values) => {
    const text = await complete(values);
    setOutput(text);
  }}
  output={output}
/>
```

可选：`npx @joyui/cli add ai-playground-template --yes`。
