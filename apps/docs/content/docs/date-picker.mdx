触发器打开弹出月历：单日用 `DatePicker`，区间用 `DateRangePicker`。确认前可在底部芯片里改日期。

<ComponentDocPreview slug="date-picker" />

## 安装

```bash
npx @joyui/cli add date-picker --yes
```

或通过 JoyUI MCP / CLI 安装。

## 单日

默认触发器；`isDisabled` 禁用整控件。

<DemoFrame
  fileName="date-picker-single.tsx"
  code={`import { parseDate } from "@internationalized/date";
import { DatePicker } from "@/components/base/date-picker/date-picker";

<>
  <DatePicker aria-label="开始日期" defaultValue={parseDate("2026-11-13")} />
  <DatePicker aria-label="禁用" isDisabled defaultValue={parseDate("2026-11-01")} />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <DatePickerSinglePreview />
</DemoFrame>

## 区间

双月视图 + 快捷区间侧栏（见组件实现）。

<DemoFrame
  fileName="date-picker-range.tsx"
  code={`import { parseDate } from "@internationalized/date";
import { DateRangePicker } from "@/components/base/date-picker/date-range-picker";

<DateRangePicker
  aria-label="活动区间"
  placeholder="选择日期区间"
  defaultValue={{
    start: parseDate("2026-11-10"),
    end: parseDate("2026-11-16"),
  }}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <DatePickerRangePreview />
</DemoFrame>

## 应用场景

报表筛选条：两个单日选择器拼成起止。

<DemoFrame
  fileName="date-picker-filter.tsx"
  code={`import { parseDate } from "@internationalized/date";

<div className="rounded-2xl border p-4">
  <p>报表筛选</p>
  <DatePicker aria-label="起始日" defaultValue={parseDate("2026-11-01")} />
  <span>至</span>
  <DatePicker aria-label="结束日" defaultValue={parseDate("2026-11-30")} />
</div>`}
