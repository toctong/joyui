层级路径导航。`BreadcrumbItem` 支持 `href`、`icon`、`current`。下方是**同一个** Breadcrumb 的不同配置。

<ComponentDocPreview slug="breadcrumb" />

## 安装

```bash
npx @joyui/cli add breadcrumb --yes
```

或通过 JoyUI MCP / CLI 安装。

## 图标

为关键节点传入 Remix Icon 组件引用。

<DemoFrame
  fileName="breadcrumb-icons.tsx"
  code={`import { RiFolder3Line, RiHomeLine, RiSettings3Line } from "@remixicon/react";
import { Breadcrumb, BreadcrumbItem } from "@/components/base/breadcrumb/breadcrumb";

<Breadcrumb aria-label="带图标面包屑">
  <BreadcrumbItem icon={RiHomeLine} href="#">工作区</BreadcrumbItem>
  <BreadcrumbItem icon={RiFolder3Line} href="#">项目</BreadcrumbItem>
  <BreadcrumbItem icon={RiSettings3Line} current>设置</BreadcrumbItem>
</Breadcrumb>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <BreadcrumbIconPreview />
</DemoFrame>

## 深层路径

多级文本路径，末项标记 `current`。

<DemoFrame
  fileName="breadcrumb-deep.tsx"
  code={`import { Breadcrumb, BreadcrumbItem } from "@/components/base/breadcrumb/breadcrumb";

<Breadcrumb aria-label="深层路径">
  <BreadcrumbItem href="#">首页</BreadcrumbItem>
  <BreadcrumbItem href="#">发现</BreadcrumbItem>
  <BreadcrumbItem href="#">电影</BreadcrumbItem>

## 应用场景

设置页顶栏：路径 + 简短说明。
