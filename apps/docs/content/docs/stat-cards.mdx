## 安装

```bash
npx joyui add stat-cards --yes
```

或通过 JoyUI MCP / CLI 安装。


## 应用场景

用于仪表盘 KPI 区：传入业务 series 即可替换演示数据，详见下方数据项 / API。

上方预览中的文案、选项与数据均可替换为业务配置；不要复制写死的演示常量到生产。
