带事件芯片与详情弹出的完整月历为 **Pro 模板预览**。开源侧请用 `DateCalendar` / `DatePicker` / `MeetingScheduler` 做选日与预约。

<ProComponentDoc slug="calendar" name="日历" />

## 安装（选日组件）

```bash
pnpm add @joyui/react
```

```tsx
import { DateCalendar, DatePicker, MeetingScheduler } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add date-picker --yes`。

## 相关：页面内区间

无事件芯片时，用 `DateRangeCalendar` 做入住 / 筛选。
