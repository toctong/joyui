`Dropdown` + `DropdownTrigger` + `DropdownPopover`。下方是**同一个** Dropdown 的不同配置。

<ComponentDocPreview slug="dropdown" />

## 安装

```bash
npx @joyui/cli add dropdown --yes
```

或通过 JoyUI MCP / CLI 安装。

## 分组与分割线

`DropdownGroup` 的 `label` + `DropdownDivider`。

<DemoFrame
  fileName="dropdown-groups.tsx"
  code={`import {
  Dropdown, DropdownDivider, DropdownGroup, DropdownItem, DropdownPopover, DropdownTrigger,
} from "@/components/base/dropdown/dropdown";

<Dropdown>
  <DropdownTrigger>添加</DropdownTrigger>
  <DropdownPopover aria-label="添加菜单">
    <DropdownGroup label="内容">
      <DropdownItem>新建文档</DropdownItem>
      <DropdownItem>上传文件</DropdownItem>
    </DropdownGroup>
    <DropdownDivider />
    <DropdownGroup label="协作">
      <DropdownItem>邀请成员</DropdownItem>
    </DropdownGroup>
  </DropdownPopover>
</Dropdown>`}
