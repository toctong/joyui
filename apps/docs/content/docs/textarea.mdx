## 安装

```bash
npx @joyui/cli add textarea --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸

`size="medium" | "small"`，配合 `rows`。

<DemoFrame
  fileName="textarea-sizes.tsx"
  code={`import { Textarea } from "@/components/base/textarea/textarea";

<>
  <Textarea size="medium" label="中号" placeholder="补充说明…" rows={3} />
  <Textarea size="small" label="小号" placeholder="补充说明…" rows={3} />
</>`}

## 自动增高与字数

`autoResize` + `maxRows`；`maxLength` + `showCount` 显示字数。

<DemoFrame
  fileName="textarea-autoresize.tsx"
  code={`import { Textarea } from "@/components/base/textarea/textarea";

<Textarea
  label="反馈"
  placeholder="输入时自动增高…"
  autoResize
  maxRows={6}
  maxLength={120}
  showCount
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <TextareaAutoResizePreview />
</DemoFrame>
