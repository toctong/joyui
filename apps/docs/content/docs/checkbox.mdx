多选控件。下方是**同一个** `Checkbox` 的不同状态；选项块可用 `CheckboxCard`。

<ComponentDocPreview slug="checkbox" />

## 安装

```bash
npx @joyui/cli add checkbox --yes
```

或通过 JoyUI MCP / CLI 安装。

## 状态

未选中 · 已选中 · `isIndeterminate` 半选 · `isDisabled` · `size="sm"`。

<DemoFrame
  fileName="checkbox-states.tsx"
  code={`import { Checkbox } from "@/components/base/checkbox/checkbox";

  <Checkbox isIndeterminate>半选</Checkbox>
  <Checkbox isDisabled>禁用</Checkbox>
