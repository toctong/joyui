<ComponentDocPreview slug="card" />

## 安装

```bash
npx @joyui/cli add card --yes
```

或通过 JoyUI MCP / CLI 安装。

## 变体

`outline`（默认白底描边）· `soft`（仪表盘内嵌浅底）· `ghost`（只保留间距）。
