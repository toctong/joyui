通用档案积木：`ProfileInfoCard`、`AlertFeedCard`、`WeekRangePill`。数据全部可注入，不再绑定医疗文案。

<ComponentDocPreview slug="profile-cards" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import {
  AlertFeedCard,
  ProfileInfoCard,
  WeekRangePill,
} from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add profile-cards --yes`。

旧名 `PatientInfoCard` / `ImportantAlertsCard` / slug `medical` 仍可导入，建议迁移到新名。
