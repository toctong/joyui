语音输入空闲 / 聆听态。`active` 打开脉冲。

<ComponentDocPreview slug="voice-ring" />

## 安装

```bash
npx @joyui/cli add voice-ring --yes
```

## 聆听态

包裹图标按钮，切换 `active`。

<DemoFrame
  fileName="voice-ring-active.tsx"
  code={`import { RiMicLine } from "@remixicon/react";
import { Button } from "@/components/base/buttons/button";
import { VoiceRing } from "@/components/base/voice-ring/voice-ring";

<>
  <VoiceRing>
    <Button iconOnly leadingIcon={RiMicLine} aria-label="麦克风" variant="secondary" />
  </VoiceRing>
  <VoiceRing active>
    <Button iconOnly leadingIcon={RiMicLine} aria-label="正在聆听" />
  </VoiceRing>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
