分享链接、登录票据、设备配对。依赖 `qrcode` 已内置。

<ComponentDocPreview slug="qr-code" />

## 安装

```bash
npx @joyui/cli add qr-code --yes
```

## 纠错级别

`L` · `M` · `Q` · `H` — 级别越高可容纳更多遮挡（如 Logo）。

<DemoFrame
  fileName="qr-code-levels.tsx"
  code={`import { QrCode } from "@/components/base/qr-code/qr-code";

<>
  <QrCode value="https://www.joyui.top" size={120} level="L" />
  <QrCode value="https://www.joyui.top" size={120} level="H" />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <QrCodeLevelPreview />
</DemoFrame>

## 中心叠加

`overlay` 放 Logo；建议配合 `level="H"`。

<DemoFrame
  fileName="qr-code-overlay.tsx"
  code={`import { QrCode } from "@/components/base/qr-code/qr-code";

<QrCode
  value="https://www.joyui.top"
  size={160}
  level="H"
  overlay={<span>Joy</span>}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-secondary-default p-8"
>
  <QrCodeOverlayPreview />
</DemoFrame>
