## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AuthCard, AuthMediaCarousel } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add auth-card --yes`。

## 媒体分栏

`media` 打开双栏；`layout="inline"` 压缩社交按钮。可传自定义节点，或 `AuthMediaCarousel`（需 `slides`）。

<DemoFrame
  fileName="auth-card-media.tsx"
  code={`import { AuthCard } from "@joyui/react";

<AuthCard
  mode="signin"
  layout="inline"
  providers={["google", "github", "apple"]}
  media={
    <div className="flex size-full items-end bg-linear-to-br from-accent-500 to-accent-800 p-6">
      <p className="text-title-2-medium text-white">Welcome back</p>
    </div>
  }
/>`}
  canvasClassName="min-h-[480px] items-center justify-center bg-background-secondary-default p-6"
>
  <AuthCardMediaPreview />
</DemoFrame>

## 自定义表单（`children`）

```tsx
import { AuthCard, Button, Input } from "@joyui/react";

<AuthCard title="Sign in" description="Use your workspace account.">
  <form className="flex flex-col gap-4" onSubmit={handleSubmit}>
    <Input name="username" label="Username" isRequired />
    <Input name="password" type="password" label="Password" isRequired />
    <Button type="submit" className="w-full">Continue</Button>
  </form>
</AuthCard>
```
