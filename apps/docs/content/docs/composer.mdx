胶囊输入：通过 `models`、`defaultModelId`、`placeholder`、`branch` / `project` / `agentMode` / `contextPct` 配置型号菜单与状态栏。预览是同一 `Composer` 的不同 props，不是写死控件。

<ComponentDocPreview slug="composer" />

## 安装

```bash
npx @joyui/cli add composer --yes
```

或通过 JoyUI MCP / CLI 安装。

## 应用场景

AI 聊天页底部输入条：把 `models` 换成你们的网关型号列表，状态栏绑定当前 git 分支与项目名。

```tsx
<Composer
  models={[
    { id: "gpt-5.6-sol", name: "GPT-5.6 Sol" },
    { id: "fable-5", name: "Fable 5" },
  ]}
  defaultModelId="fable-5"
  branch="主要"
  project="项目海"
  contextPct={57}
/>
```
