一套对话输入表面：基础胶囊条、附件上传条、工作中虹彩光带、以及更完整的卡片面板。按需安装对应 slug，导航只保留本页。

## 胶囊输入框

通过 `models`、`defaultModelId`、`placeholder`、`branch` / `project` / `agentMode` / `contextPct` 配置型号菜单与状态栏。

<ComponentDocPreview slug="composer" />

整库使用时从子路径导入（需 TipTap peers，见 [安装](/docs/installation)）：

```tsx
import { Composer } from "@joyui/react/composer";
```

```bash
npx @joyui/cli add composer --yes
```

## 输入框附件

附件列表通过 `attachments` 传入；`progress: 0` 播上传环，到 `100` 显示「上传成功！」并切黄边。

<ComponentDocPreview slug="composer-attachments" />

```bash
npx @joyui/cli add composer-attachments --yes
```
