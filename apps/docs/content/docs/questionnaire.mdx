## 安装

当前为文档演示形态：

```bash
pnpm add @joyui/react
```

```tsx
import { Button, Radio, RadioGroup } from "@joyui/react";
```

可用基础组件拼逐步问卷；高度动画可用 `Collapsible` 或 `motion`。
