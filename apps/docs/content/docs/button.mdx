主操作、次要、幽灵与危险四种 `variant`，三档 `size`，图标通过 `leadingIcon` / `trailingIcon` 传入组件引用。禁用态同时支持原生 `disabled` 与 React Aria 风格 `isDisabled`。下方预览是**同一个** `Button` 的不同配置。

<ComponentDocPreview slug="button" />

## 安装

```bash
npx @joyui/cli add button --yes
```

或通过 JoyUI MCP / CLI 安装。

## 变体

通过 `variant` 切换语义色。

## 图标

传入 Remix Icon **组件引用**，不要传已渲染的元素。

<DemoFrame
  fileName="button-icons.tsx"
  code={`import { RiAddLine, RiArrowRightLine } from "@remixicon/react";
import { Button } from "@/components/base/buttons/button";

<>
  <Button leadingIcon={RiAddLine}>New project</Button>
  <Button trailingIcon={RiArrowRightLine}>Continue</Button>
  <Button iconOnly leadingIcon={RiAddLine} aria-label="Add" />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <ButtonIconPreview />
</DemoFrame>

## 应用场景

表单页脚或卡片工具栏：取消（ghost）+ 次要 + 主操作。

<DemoFrame
  fileName="button-toolbar.tsx"
