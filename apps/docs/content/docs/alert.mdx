<ComponentDocPreview slug="alert" />

## 安装

```bash
npx @joyui/cli add alert --yes
```

或通过 JoyUI MCP / CLI 安装。

## 语气

`tone`：`info` · `success` · `warning` · `error`。图标可按语气默认，也可传入自定义 `icon`。

<DemoFrame
  fileName="alert-tones.tsx"
  code={`import { Alert } from "@/components/base/alert/alert";

<>
  <Alert tone="info" title="同步已暂停">上游接口限流。</Alert>
  <Alert tone="success" title="设置已保存">规则已生效。</Alert>
  <Alert tone="warning" title="Cookie 即将过期">请重新登录。</Alert>
  <Alert tone="error" title="转存失败">链接无效。</Alert>
</>`}
  canvasClassName="min-h-40 items-start justify-center bg-background-primary-default p-8"
>
  <AlertTonePreview />
</DemoFrame>

## 应用场景

新建任务表单：解析失败时用 `role="alert"` 的错误条，文案可换成业务错误。

<DemoFrame
  fileName="alert-form.tsx"
  code={`import { Alert } from "@/components/base/alert/alert";

<Alert tone="error" title="无法解析分享链接" role="alert">
  请确认链接完整，且未设置提取码限制。
</Alert>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-secondary-default p-8"
>
  <AlertScenarioPreview />
</DemoFrame>
