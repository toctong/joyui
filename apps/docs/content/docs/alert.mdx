常驻在布局里的反馈条。短暂成功提示优先用 Toast。

<ComponentDocPreview slug="alert" />

## 安装

```bash
npx @joyui/cli add alert --yes
```

```tsx
import { Alert } from "@joyui/react";

<Alert tone="warning" title="Cookie expired">
  Re-sign Quark in Settings, then retry the transfer.
</Alert>
```

## 应用场景

登录失败、设置保存错误、缺 Cookie、Discovery 上游报错等页面级提示。  
`tone`：`info` · `success` · `warning` · `error`。
