医疗档案仪表盘积木：`PatientInfoCard`、`WeekRangePill`、`ImportantAlertsCard`。

<ComponentDocPreview slug="medical" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import {
  ImportantAlertsCard,
  PatientInfoCard,
  WeekRangePill,
} from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add medical --yes`。

## 组合

```tsx
<div className="grid gap-4 sm:grid-cols-[220px_minmax(0,1fr)]">
  <PatientInfoCard />
  <ImportantAlertsCard /> {/* 内含 WeekRangePill */}
</div>
```

`ImportantAlertsCard` 顶栏已带 `WeekRangePill`；单独使用周切换时再引入 `WeekRangePill`。演示文案经 `useTemplateCopy` 本地化。
