## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AuthTemplate } from "@joyui/react";

<AuthTemplate mode="signin" />
```

默认单栏；传 `media` / `mediaSlot` + `withMedia` 开启分栏。可选：`npx @joyui/cli add auth-template --yes`。
