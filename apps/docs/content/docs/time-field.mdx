按段输入时 / 分（可选秒）：会议开始、营业时间、提醒时刻。

<ComponentDocPreview slug="time-field" />

## 安装

```bash
npx @joyui/cli add time-field --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸

`medium`（36px）· `small`（32px）。
