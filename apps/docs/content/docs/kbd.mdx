快捷键提示胶囊，用于命令面板、表单提示与工具栏。

<ComponentDocPreview slug="kbd" />

## 安装

```bash
npx @joyui/cli add kbd --yes
```

或通过 JoyUI MCP / CLI 安装。

## 组合键

多个 `Kbd` 并排表示修饰键与主键组合。

<DemoFrame
  fileName="kbd-combo.tsx"
  code={`import { Kbd } from "@/components/base/kbd/kbd";

<>
  <div className="flex items-center gap-1">
    <Kbd>⌘</Kbd>
    <Kbd>K</Kbd>
  </div>
  <div className="flex items-center gap-1">
    <Kbd>Ctrl</Kbd>
    <Kbd>Shift</Kbd>
    <Kbd>P</Kbd>
  </div>
  <Kbd>Esc</Kbd>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <KbdComboPreview />
</DemoFrame>
