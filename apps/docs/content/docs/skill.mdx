JoyUI 提供标准 Agent Skill（`SKILL.md`）：完整组件目录、**npm 整库 + 内置 CSS** 用法、语义 token 与页面模式。

## 安装

```bash
npx @joyui/cli@latest skill
```

全局：`npx @joyui/cli@latest skill --global`  
其他客户端：`--client codex` 或 `--path <dir>`

也可通过 MCP：`install_skill`。

## Skill 会强调什么

1. `pnpm add @joyui/react`
2. `@import "@joyui/react/styles.css"`
3. `import { Button, … } from "@joyui/react"`
4. 语义 token + `cn`/`cx`；禁止 raw palette
5. CLI `add` 仅作可选源码拷贝
