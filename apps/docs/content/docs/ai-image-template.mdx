## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AiImageTemplate } from "@joyui/react";

<AiImageTemplate
  className="h-[640px]"
  onSubmit={(prompt, meta) => generate(prompt, meta)}
/>
```

可选：`npx @joyui/cli add ai-image-template --yes`。
