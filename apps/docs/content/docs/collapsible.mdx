## 安装

```bash
npx @joyui/cli add collapsible --yes
```

或通过 JoyUI MCP / CLI 安装。

## 基础

必填 `title`，默认收起。

<DemoFrame
  fileName="collapsible-basic.tsx"
  code={`import { Collapsible } from "@/components/base/collapsible/collapsible";

<Collapsible title="高级筛选">
  可按状态、负责人与更新时间缩小结果范围。
</Collapsible>`}

## 默认展开

`defaultExpanded` 初始打开。

<DemoFrame
  fileName="collapsible-expanded.tsx"
  code={`import { Collapsible } from "@/components/base/collapsible/collapsible";

  仅工作区成员可见；导出操作会写入审计日志。
