## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { /* … */ } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add task-list --yes`。



## 应用场景

组合块可直接嵌入应用壳：通过 props / data 接入业务状态，勿写死文案。

上方预览中的文案、选项与数据均可替换为业务配置；不要复制写死的演示常量到生产。
