## 安装

当前为文档演示形态，尚无独立 registry 包导出。推荐：

```bash
pnpm add @joyui/react
```

```tsx
import { LogRow, WorkingRow, useLogMotion } from "@joyui/react";
```

或 `npx @joyui/cli add agent-log --yes` 拷贝源码后按业务组装。

## 与 agent-log

| 需求 | 用法 |
|------|------|
| 完成行 | `<LogRow first last reduce={…}>…</LogRow>` |
| 进行中 | `<WorkingRow label="…" reduce={…} />` |
| 节奏 | `useRevealTicker({ total, revealed? })` |
