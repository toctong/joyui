设置账号行、搜索结果、日志条目等，用 `List` + `ListItem` 替代手写 `divide-y` 盒子。

<ComponentDocPreview slug="list" />

## 安装

```bash
npx @joyui/cli add list --yes
```

## 可点击行

`interactive` 加上悬停底与指针；`trailing` 可放 Chip。

<DemoFrame
  fileName="list-interactive.tsx"
  code={`import { Chip } from "@/components/base/badges/chip";
import { List, ListItem } from "@/components/base/list/list";

<List className="w-full max-w-md">
  <ListItem title="CloudSaver" description="插件端点" interactive trailing={<Chip color="neutral" variant="subtle">off</Chip>} />
</List>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <ListInteractivePreview />
</DemoFrame>

## 前置槽

`leading` 放头像或序号；`divided={false}` 去掉行间分隔。

<DemoFrame
  fileName="list-leading.tsx"
  code={`import { List, ListItem } from "@/components/base/list/list";

<List divided={false}>
  <ListItem leading={<span>A</span>} title="账号同步" description="每 15 分钟" />
</List>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-secondary-default p-8"
>
  <ListLeadingPreview />
</DemoFrame>
