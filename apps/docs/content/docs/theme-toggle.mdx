浅色 · 系统 · 深色，写入本地存储；`system` 跟随 `prefers-color-scheme`。用 `AccentSwitcher` / `setAccent` 切换品牌主色。

<ComponentDocPreview slug="theme-toggle" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { ThemeToggle, AccentSwitcher, setAccent } from "@joyui/react";

setAccent("violet");
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add theme-toggle --yes`。

## Accent 换肤

预设：`blue` · `violet` · `teal` · `orange` · `rose` · `mono`。写入 `data-accent` 与 `JoyUI:accent`。设置页用 `appearance="cards"`（色块 + 中文名）；页头紧凑色点用默认 `plain`。

<DemoFrame
  fileName="accent-switcher.tsx"
  code={`import { AccentSwitcher, setAccent } from "@joyui/react";

<>
  <AccentSwitcher appearance="cards" />
  <AccentSwitcher size="small" />
  <button type="button" onClick={() => setAccent("teal")}>Teal</button>
</>`}
