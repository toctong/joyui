手动切换浅色 / 深色，写入本地存储；不跟随系统偏好。

<ComponentDocPreview slug="theme-toggle" />

## 安装

```bash
npx @joyui/cli add theme-toggle --yes
```

或通过 JoyUI MCP / CLI 安装。

## 外观

`sidebar` · `segmented` · `glass-segmented`（着陆页玻璃肤）。
