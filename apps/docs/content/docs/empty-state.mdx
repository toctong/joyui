一套空状态家族：基础占位通过 `title` / `description` / `action` / `size` 配置；搜索与插画场景换用下方变体，API 各自独立、安装按 slug。

## 基础空态

标题必填；描述与 `action`（通常放 Button）可选。`size="sm"` 适合表格内部；页面级用默认 `md`。

<ComponentDocPreview slug="empty-state" />

```bash
npx @joyui/cli add empty-state --yes
```

### 尺寸

`sm`（表格内）· `md`（页面级，默认）。

<DemoFrame
  fileName="empty-state-sizes.tsx"
  code={`import { RiFolderOpenLine, RiInbox2Line } from "@remixicon/react";
import { EmptyState } from "@/components/base/empty-state/empty-state";

<>
  <EmptyState size="sm" icon={RiFolderOpenLine} title="暂无日志" description="表格内紧凑空态（sm）。" />
  <EmptyState size="md" icon={RiInbox2Line} title="暂无转存" description="页面级默认空态（md）。" />
</>`}

</DemoFrame>

### 带操作

在 `action` 插槽放入 Button，引导用户恢复有数据的状态。

<DemoFrame
  fileName="empty-state-action.tsx"
  code={`import { Button } from "@/components/base/buttons/button";
import { EmptyState } from "@/components/base/empty-state/empty-state";

<EmptyState
  title="还没有任务"
  description="在设置中添加 Quark Cookie，然后创建第一个转存任务。"
  action={<Button size="small" variant="secondary">打开设置</Button>}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <EmptyStateActionPreview />
</DemoFrame>
