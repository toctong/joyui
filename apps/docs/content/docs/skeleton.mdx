内容形占位，加载后模糊淡入。`Skeleton` 控制形状，`SkeletonText` 快速堆叠多行。

<ComponentDocPreview slug="skeleton" />

## 安装

```bash
npx @joyui/cli add skeleton --yes
```

或通过 JoyUI MCP / CLI 安装。

## 形状

`rect` · `circle` · `text`。
