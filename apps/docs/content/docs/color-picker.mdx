让用户凭眼睛、用十六进制值或从你的预设中选择品牌色、标签颜色或图表系列颜色。`value` / `onChange` / `swatches` / `showAlpha` 均可配置。

<ComponentDocPreview slug="color-picker" code={COLOR_PICKER_BASIC_CODE} />

## 安装

```bash
npx @joyui/cli add color-picker --yes
```

或通过 JoyUI MCP / CLI 安装。

## 内联选择器

受控 `ColorPicker`：饱和度场、色相轨、hex 与预设色板。

## 色井弹出

`ColorWell` 是圆形色板，点击后在弹出层打开同一编辑器——适合设置行、标签色。

## 应用场景

主题定制或标签设置：多行 `ColorWell` 绑定不同业务字段（品牌 / 标签 / 图表系列）。
