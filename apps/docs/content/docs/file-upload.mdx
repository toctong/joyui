一套上传家族：基础单文件拖放含校验与进度；需要多图预览网格时换下方变体，API 各自独立、安装按 slug。

## 基础上传

拖放或点击选择；扩展名 / 大小校验，周界进度与完成回调。

<ComponentDocPreview slug="file-upload" />

```bash
npx @joyui/cli add file-upload --yes
```

### 限制类型与大小

`allowedExtensions` 与 `maxBytes` 控制可接受文件。

<DemoFrame
  fileName="file-upload-restrict.tsx"
  code={`import { FileUpload } from "@/components/base/file-upload/file-upload";

<FileUpload
  allowedExtensions={["png", "jpg", "jpeg"]}
  maxBytes={2 * 1024 * 1024}
  onUploadComplete={(file) => console.log(file.name)}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <FileUploadRestrictPreview />
</DemoFrame>
