短延迟说明文案。`TooltipTrigger` 包裹触发器，`Tooltip` 配置尺寸、方位与箭头。下方是**同一个** Tooltip 的不同配置。

<ComponentDocPreview slug="tooltip" />

## 安装

```bash
npx @joyui/cli add tooltip --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸与箭头

`size="sm" | "md"`；`showArrow={false}` 可关闭箭头。

<DemoFrame
  fileName="tooltip-sizes.tsx"
  code={`import { Button } from "@/components/base/buttons/button";
import { Tooltip, TooltipTrigger } from "@/components/base/tooltip/tooltip";

<>
  <TooltipTrigger delay={0}>
    <Button variant="secondary" size="small">小号</Button>
    <Tooltip size="sm">快捷说明 · sm</Tooltip>
  </TooltipTrigger>
  <TooltipTrigger delay={0}>
    <Button variant="secondary" size="small">无箭头</Button>
    <Tooltip showArrow={false}>关闭箭头</Tooltip>
  </TooltipTrigger>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <TooltipSizePreview />
</DemoFrame>

## 方位
