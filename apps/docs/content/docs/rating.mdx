一套评分家族：基础星级；需要心情 / NPS 表情量表时换下方变体。

## 星级

发现页评分、评论卡片。`interactive` 时点击星星触发 `onChange`。

<ComponentDocPreview slug="rating" />

```bash
npx @joyui/cli add rating --yes
```

### 尺寸

`sm` · `md`；可用 `max` 调整星数。

<DemoFrame
  fileName="rating-sizes.tsx"
  code={`import { Rating } from "@/components/base/rating/rating";

<>
  <Rating value={4} size="sm" aria-label="小尺寸评分" />
  <Rating value={3.6} size="md" aria-label="中尺寸评分" />
  <Rating value={4} max={7} size="md" aria-label="七星评分" />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <RatingSizePreview />
</DemoFrame>

### 交互

开启 `interactive` 后点击更新 `value`。

<DemoFrame
  fileName="rating-interactive.tsx"
  code={`import { useState } from "react";
import { Rating } from "@/components/base/rating/rating";

function Example() {
  const [value, setValue] = useState(3);
  return <Rating interactive value={value} onChange={setValue} aria-label="可点选评分" />;
}`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <RatingInteractivePreview />
</DemoFrame>
