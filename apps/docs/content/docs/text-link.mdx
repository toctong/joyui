段落内导航或次要跳转。`muted` 默认次级色，悬停变品牌色。

<ComponentDocPreview slug="text-link" />

## 安装

```bash
npx @joyui/cli add text-link --yes
```

## 色调与尺寸

`sm` / `md`；`muted` 降低默认强调。
