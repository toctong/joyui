---
title: "RTL 支持"
description: "通过 locale 切换阅读方向：DirectionProvider、逻辑样式，以及邮箱 / OTP 等仍保持 LTR 的例外。"
---

JoyUI 的阅读方向由 **locale** 决定，而不是单独的 `direction` prop。把 `locale` 设为阿拉伯语（`ar`）、希伯来语（`he`）等 BCP 47 标签后，React Aria 会解析出 `dir="rtl"`，并同步：

- 文档方向（`lang` / `dir`）
- 键盘与焦点行为
- 弹出层 / Portal（Modal、Drawer、Popover、菜单等）

仅给 CSS 写 `dir="rtl"` **不够**：没有 Provider 时，React Aria 的导航与 portal 对齐不会跟着变。

## 推荐：JoyUIProvider

若应用已用整库 `@joyui/react`，在根节点包 `JoyUIProvider` 即可（内部已包含 `DirectionProvider`）：

```tsx
import { JoyUIProvider, Button, Input } from "@joyui/react";

export function App() {
  return (
    <JoyUIProvider locale="ar">
      <Button variant="primary">حفظ</Button>
      <Input label="الاسم" />
    </JoyUIProvider>
  );
}
```

整页 RTL 时，请让 `<html>` 的 `lang` / `dir` 与 locale 一致：

```tsx
<html lang="ar" dir="rtl">
  <body>{/* … */}</body>
</html>
```

文案目录与 RTL 是两件事：内置消息目前主要是 `en` / `zh-CN`；`locale="ar"` 会切布局方向，但不会自动带上阿拉伯语文案。覆盖文案见 [国际化](/docs/i18n)。

## 仅布局：DirectionProvider

只需要方向、不需要内置文案时，可单独使用：

```tsx
import { DirectionProvider, useDirection } from "@joyui/react";

export function Root({ children }: { children: React.ReactNode }) {
  return (
    <html lang="he" dir="rtl">
      <body>
        <DirectionProvider locale="he">{children}</DirectionProvider>
      </body>
    </html>
  );
}

function ChevronHint() {
  const direction = useDirection(); // "ltr" | "rtl"
  return <span>{direction}</span>;
}
```

`DirectionProvider` 必填 `locale`；不要传 `dir` / `lang`（由内部根据 locale 写入）。默认边界是 `display: contents`，不打断外层布局。嵌套 Provider 可做局部语言区域。

## 逻辑样式约定

组件与文档约定使用逻辑属性，避免写死 `left` / `right`：

| 物理（避免） | 逻辑（推荐） |
| --- | --- |
| `pl` / `pr`、`ml` / `mr` | `ps` / `pe`、`ms` / `me` |
| `left` / `right`、`text-left` | `start` / `end`、`text-start` / `text-end` |
| `border-l` / `rounded-r` | `border-s` / `rounded-e` |

Drawer 等布局用 `placement: "start" | "end"`，在 RTL 下会镜像到正确一侧。

部分导航箭头会通过 `rtl:rotate-180` 翻转；装饰性图标、Logo、涨跌箭头等**不会**盲目翻转。图表（Recharts）区域保持 LTR，避免坐标轴被镜像。

## 仍保持 LTR 的内容

以下输入默认按 LTR 处理（符合常见产品习惯）：

- `Input`：`type` 为 email / url / tel 时默认 `dir="ltr"`；也可用 `inputDir="ltr" | "rtl" | "auto"` 覆盖
- `InputOtp`：根节点固定 LTR
- 业务里的 URL、验证码、纯数字串：可用 `dir="ltr"` 或 `<bdi>` 包一层
