时间范围、视图模式等短选项切换。拇指位移动画跟随选中项。

<ComponentDocPreview slug="segmented-control" />

## 安装

```bash
npx @joyui/cli add segmented-control --yes
```

## 变体

`solid`（默认填充轨）· `plain`（轻量）。
