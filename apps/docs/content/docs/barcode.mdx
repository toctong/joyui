SKU、运单号、票务码。默认 `CODE128`；依赖 jsbarcode 已内置。下方是**同一个** `Barcode` 的不同配置。

<ComponentDocPreview slug="barcode" />

## 安装

```bash
npx @joyui/cli add barcode --yes
```

或通过 JoyUI MCP / CLI 安装。

## 格式

`format` 切换编码（如 `CODE128`、`EAN13`）；`height` 控制条高。

<DemoFrame
  fileName="barcode-formats.tsx"
  code={`import { Barcode } from "@/components/base/barcode/barcode";

<>
  <Barcode value="MH-2026-0312" format="CODE128" />
  <Barcode value="5901234123457" format="EAN13" height={48} />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <BarcodeFormatPreview />
</DemoFrame>

## 显示数值

`displayValue` 控制条码下方文字（默认 `true`）。

<DemoFrame
  fileName="barcode-display.tsx"
  code={`import { Barcode } from "@/components/base/barcode/barcode";

<>
  <Barcode value="TICKET-8841" displayValue height={56} />
  <Barcode value="TICKET-8841" displayValue={false} height={56} />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <BarcodeDisplayPreview />
</DemoFrame>

## 与二维码怎么选

| 场景 | 组件 |
|------|------|
| URL / 长文本 / 配对 | `QrCode` |
| 纯数字/短 ID、扫码枪 | `Barcode` |
