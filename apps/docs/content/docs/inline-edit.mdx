## 安装

```bash
npx @joyui/cli add inline-edit --yes
```

## 受控保存

`value` + `onSave` 回写业务状态。

<DemoFrame
  fileName="inline-edit-save.tsx"
  code={`import { useState } from "react";
import { InlineEdit } from "@/components/base/inline-edit/inline-edit";

function Example() {
  const [value, setValue] = useState("季度报告");
  return <InlineEdit value={value} onSave={setValue} />;
}`}
