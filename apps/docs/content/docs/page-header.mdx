仪表盘路由顶部的标准页眉。小屏自动折行。

<ComponentDocPreview slug="page-header" />

## 安装

```bash
npx @joyui/cli add page-header --yes
```

## 带操作

`actions` 可放 Button、Input、SegmentedControl。

<DemoFrame
  fileName="page-header-actions.tsx"
  code={`import { Button } from "@/components/base/buttons/button";
import { Input } from "@/components/base/input/input";
import { PageHeader } from "@/components/base/page-header/page-header";

<PageHeader
  title="任务"
  description="自动转存、命名规则与进度"
  actions={
    <>
      <Input aria-label="搜索任务" placeholder="搜索任务" />
      <Button size="small">新建任务</Button>
    </>
  }
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <PageHeaderActionsPreview />
</DemoFrame>
