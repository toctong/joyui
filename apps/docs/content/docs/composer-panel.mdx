两行卡片输入：`placeholder`、`branch` / `project` / `modeLabel` / `contextPct`、`attachments`、`mentions` 均为 props。型号菜单与权限芯片属于同一输入栏配置，不是独立写死菜单。

<ComponentDocPreview slug="composer-panel" />

## 安装

```bash
npx joyui add composer-panel --yes
```

或通过 JoyUI MCP / CLI 安装。

## 应用场景

Agent IDE 底部输入：状态页签绑定仓库分支与工作区；`mentions` 接项目文件树；附件条接上传队列。

```tsx
<ComposerPanel
  branch="主要"
  project="项目海"
  modeLabel="绕过所有"
  contextPct={57}
  placeholder="输入消息，用 @ 提及附件或图片…"
/>
```
