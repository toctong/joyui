一套轻提示家族：命令式 `toast()` 堆叠为通知卡片；异步流程用 `toastPromise` 做 loading→成功/失败变形。API 各自独立、安装按 slug。

## 基础

任意处 `toast()`，页面根部挂一个 `<Toaster />`。

<ComponentDocPreview slug="toast" />

```bash
npx @joyui/cli add toast --yes
```

### 状态

与 `Notification` 共享状态色：信息 · 成功 · 错误 · 中性。

<DemoFrame
  fileName="toast-status.tsx"
  code={`import { Notification } from "@/components/base/notification/notification";

  <Notification status="success" title="已保存更改" />
  <Notification status="error" title="上传失败" description="文件超过 20MB。" />
  <Notification status="neutral" title="今晚 23:00 维护" />
</div>`}

### 触发示例

交互按钮放在 client 预览里（MDX 是 Server Component，不能直接写 `onClick`）。

<DemoFrame
  fileName="toast-triggers.tsx"
  code={`import { Button } from "@/components/base/buttons/button";
import { toast, Toaster } from "@/components/base/toast/toast";

<>
  <Toaster />
  <div className="flex flex-wrap gap-2">
    <Button variant="secondary" onClick={() => toast.info("已加入队列")}>信息</Button>
    <Button onClick={() => toast.success("已保存更改")}>成功</Button>
    <Button variant="danger" onClick={() => toast.error("上传失败", { description: "文件超过 20MB。" })}>错误</Button>
  </div>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <ToastTriggersPreview />
</DemoFrame>

## Promise 变形

先出 loading 卡，Promise 落定后原地变成成功或错误——适合保存、导出、上传。

<ComponentDocPreview slug="toast-promise" />
