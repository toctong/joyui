## 常用类名

| 用途 | 类名 |
|------|------|
| 主文字 | `text-text-primary` |
| 次文字 | `text-text-secondary` |
| 三级文字 | `text-text-tertiary` |
| 主表面 | `bg-background-primary-default` |
| 次表面 | `bg-background-secondary-default` |
| 边框 | `border-border-default` |
| 分隔 | `border-separator-border` |
| 图标 | `text-foreground-icon-primary` |

深色模式：给 `<html>` 加 `.dark`，token 自动翻转。
