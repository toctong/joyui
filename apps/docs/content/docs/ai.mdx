面向智能体 / 对话产品的组件：输入区、思考指示、流式日志、搜索轨迹与上下文仪表。

```bash
pnpm add @joyui/react
```

```tsx
import {
  AgentThinking,
  ContextMeter,
  PromptSuggestions,
  WebSearch,
} from "@joyui/react";
import { Composer } from "@joyui/react/composer";
```

主题 CSS 已内置：`@import "@joyui/react/styles.css"`。Composer 走独立入口 `@joyui/react/composer`（需 TipTap peers）。

## 怎么拼

| 场景 | 推荐组合 |
|------|----------|
| 空态对话 | `PromptSuggestions` → 填入 `Composer` |
| 一轮对话 | `ChatMessage`（user / assistant） |
| 思考披露 | `ReasoningBlock` 嵌在助手消息内 |
| 工具 / MCP | `ToolCall`；搜索专用用 `WebSearch` |
| 消息操作 | `MessageActions`（父级 `group/message`） |
| 生成中 | `AgentThinking` / `ThinkingOrbs` 叠在 Composer 上方 |
| 流式日志行 | `agent-log` 的 `LogRow` / `WorkingRow` |
| 上下文预算 | `ContextMeter` 或 Composer 内置环 |
| 引用回答 | `Citation` 行挂在消息下方 |
| 模型切换 | `ModelSelect` 放工具条 |

`Task List` / `Questionnaire` 仍为文档演示形态。
