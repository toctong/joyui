JoyUI 之前有 `PageHeader`（页内标题）和 `AdminDashboard`（整页模板），但缺少可复用的**控制台外壳**。`AppShell` 提供侧栏槽位 + 顶栏 + 可滚动内容区；`AppHeader` 是持久顶栏（面包屑 / 搜索 / 通知），与页内 `PageHeader` 分开使用。

<ComponentDocPreview slug="app-shell" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AppShell, AppHeader } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。

## 基本结构

侧栏传入 `DashboardSidebar` 或自建导航；顶栏用 `AppHeader` 放面包屑与 `NotificationBell`。
