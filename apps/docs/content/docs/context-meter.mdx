分段展示 system / tools / chat 等占用；超过 `warnAt` 时百分比转警告色。

<ComponentDocPreview slug="context-meter" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { ContextMeter } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add context-meter --yes`。

## 警告阈值与操作

`warnAt` 默认 `0.7`；`action` 可挂「压缩」等操作。
