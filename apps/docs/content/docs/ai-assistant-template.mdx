<ComponentDocPreview slug="ai-assistant-template" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AiAssistantTemplate } from "@joyui/react";

<AiAssistantTemplate
  api="/api/chat"
  className="h-[640px]"
  threads={threads}
  activeThreadId={id}
  onActiveThreadChange={setId}
  onNewThread={createThread}
/>
```

可选：`npx @joyui/cli add ai-assistant-template --yes`。
