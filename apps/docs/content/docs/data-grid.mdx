续约表、库存表等场景共用同一 `DataGrid`：传入 `data`、`columns`、`getRowId`、`onDataChange` 即可。

<ComponentDocPreview slug="data-grid" />

## 安装

```bash
npx @joyui/cli add data-grid --yes
```

或通过 JoyUI MCP / CLI 安装。

## 可编辑

提供 `onDataChange` 后单元格可改；省略则为只读。

<DemoFrame
  fileName="data-grid-editable.tsx"
  code={`<DataGrid
  aria-label="续约表"
  data={rows}
  columns={columns}
  getRowId={(row) => row.id}
  onDataChange={setRows}
  height={320}
  exportFileName="renewals.csv"
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-6"
>
  <DataGridEditablePreview />
</DemoFrame>
