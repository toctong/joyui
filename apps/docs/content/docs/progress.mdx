条形 `ProgressBar` 与环形 `ProgressCircle`，支持确定值或 `isIndeterminate`。

<ComponentDocPreview slug="progress" />

## 安装

```bash
npx @joyui/cli add progress --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸

`sm` · `md` · `lg`。

<DemoFrame
  fileName="progress-sizes.tsx"

## 模式

不确定条形进度与环形确定 / 不确定。

<DemoFrame
  fileName="progress-modes.tsx"
  code={`import { ProgressBar, ProgressCircle } from "@/components/base/progress/progress";

<>
  <ProgressBar label="准备导出" isIndeterminate description="正在打包文件…" />
  <ProgressCircle value={72} aria-label="上传进度 72%" size="lg" />
  <ProgressCircle isIndeterminate aria-label="加载中" size="lg" />
</>`}

## 应用场景

文件上传卡片：标题旁环形百分比 + 下方条形进度。
