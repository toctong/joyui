对话输入栏旁的模型切换器。`options` 含 `id` / `label` / 可选 `description` / `disabled`。

<ComponentDocPreview slug="model-select" />

## 安装

```bash
npx @joyui/cli add model-select --yes
```

## 尺寸

`medium` · `small`。

<DemoFrame
  fileName="model-select-sizes.tsx"
  code={`import { ModelSelect } from "@/components/base/model-select/model-select";

const options = [
  { id: "fable-5", label: "Fable 5", description: "均衡" },
  { id: "fast", label: "Fast", description: "低延迟" },
];

<>
  <ModelSelect options={options} defaultValue="fable-5" size="medium" />
  <ModelSelect options={options} defaultValue="fast" size="small" />
</>`}
