## 安装

```bash
npx @joyui/cli add announcement --yes
```

或通过 JoyUI MCP / CLI 安装。

## 操作与关闭

`actionLabel` 主操作；`dismissible` 显示关闭按钮。

<DemoFrame
  fileName="announcement-action.tsx"
  code={`import { Announcement } from "@/components/base/announcement/announcement";

<Announcement
  title="新功能"
  description="智能体技能已上线。"
  actionLabel="立即查看"
  dismissible
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <AnnouncementActionPreview />
</DemoFrame>

## 自定义图标

传入 Remix Icon 组件引用覆盖默认图标。

<DemoFrame
  fileName="announcement-icon.tsx"
  code={`import { RiSparklingFill } from "@remixicon/react";
import { Announcement } from "@/components/base/announcement/announcement";

<Announcement
  title="试用 Pro"
  description="解锁更多模板与图表。"
  icon={RiSparklingFill}
  actionLabel="升级"
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"

</DemoFrame>
