Header 铃铛：未读计数叠在图标上，点击弹出 [`NotificationCenter`](/docs/notification)。

<ComponentDocPreview slug="notification-bell" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { NotificationBell } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add notification-bell --yes`。

## 用法

```tsx
<NotificationBell notifications={items} />
```

不传 `notifications` 时使用内置 starter 数据，便于脚手架预览。正式接入时替换为业务通知列表（同 `NotificationCenterItem`）。
