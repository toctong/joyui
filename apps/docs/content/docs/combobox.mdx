可输入筛选的下拉选择。`ComboBox` + `ComboBoxItem`；分组用 `ComboBoxSection`。下方是**同一个** Combobox 的不同配置。

<ComponentDocPreview slug="combobox" />

## 安装

```bash
npx @joyui/cli add combobox --yes
```

或通过 JoyUI MCP / CLI 安装。

## 基础选项

`label` / `placeholder` / `defaultSelectedKey`，子项需 `id` 与 `textValue`。

<DemoFrame
  fileName="combobox-basic.tsx"
  code={`import { ComboBox, ComboBoxItem } from "@/components/base/combobox/combobox";

<ComboBox label="负责人" placeholder="搜索成员" defaultSelectedKey="maya">
  <ComboBoxItem id="maya" textValue="Maya Chen">Maya Chen</ComboBoxItem>
  <ComboBoxItem id="leo" textValue="Leo Park">Leo Park</ComboBoxItem>
</ComboBox>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"

</DemoFrame>

## 分区

`ComboBoxSection` 的 `title` 分组选项。

<DemoFrame
  fileName="combobox-sections.tsx"
  code={`import { ComboBox, ComboBoxItem, ComboBoxSection } from "@/components/base/combobox/combobox";

<ComboBox label="时区" placeholder="搜索时区" defaultSelectedKey="sha">
  <ComboBoxSection title="亚洲">
    <ComboBoxItem id="sha" textValue="上海">上海 · UTC+8</ComboBoxItem>
  </ComboBoxSection>
  <ComboBoxSection title="美洲">
    <ComboBoxItem id="sfo" textValue="旧金山">旧金山 · UTC-7</ComboBoxItem>
  </ComboBoxSection>
</ComboBox>`}

</DemoFrame>

## 应用场景
