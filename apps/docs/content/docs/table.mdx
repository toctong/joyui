基础数据表样式层；排序 / 过滤 / 分页逻辑可配合 `@tanstack/react-table` 或使用 DataTable。

<ComponentDocPreview slug="table" />

## 安装

```bash
npx @joyui/cli add table --yes
```

## 尺寸

`sm`（行高 48px）· `md`（行高 64px）。
