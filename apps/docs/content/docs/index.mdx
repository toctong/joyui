## 安装

<GettingStartedLead>
  在 React + Tailwind CSS v4 项目中接入 JoyUI。运行时依赖与主题变量会随包带上。
</GettingStartedLead>

<GettingStartedSteps>
  <GettingStartedStep step={1} title="安装依赖">
    ```bash
    pnpm add @joyui/react
    ```
  </GettingStartedStep>

  <GettingStartedStep step={2} title="引入样式">
    ```css
    @import "tailwindcss";
    @import "@joyui/react/styles.css";
    ```
  </GettingStartedStep>

  <GettingStartedStep step={3} title="包裹 Provider 并使用组件">
    ```tsx
    import { JoyUIProvider, Button, Input } from "@joyui/react";

    export function App() {
      return (
        <JoyUIProvider locale="zh-CN">
          <Button variant="primary">保存</Button>
          <Input label="邮箱" placeholder="you@company.com" />
        </JoyUIProvider>
      );
    }
    ```
  </GettingStartedStep>
</GettingStartedSteps>

完整 peer 依赖、Composer 可选包与 monorepo 说明见 [安装](/docs/installation)。

## MCP 与智能体

JoyUI 支持 MCP：连接一次，智能体即可浏览组件目录、真实用法，并写入源文件。

```json
{
  "mcpServers": {
    "joyui": {
      "command": "npx",
      "args": ["-y", "@joyui/cli@latest", "mcp"]
    }
  }
}
```

配置后可让 Agent 执行 `list_components`。详见 [MCP 服务器](/docs/mcp) 与 [智能体技能](/docs/skill)。
