JoyUI 是 React 19 + Tailwind CSS v4 + React Aria 的设计系统文档站，侧栏覆盖**快速入门 / 基础规范 / 基础组件 / 组合组件 / 图表 / 模板**全部条目。

## 三条路径

### A. 整库 npm 安装（推荐）

```bash
pnpm add @joyui/react react-aria-components @remixicon/react
```

```css
@import "tailwindcss";
@import "@joyui/react/styles.css";
```

```tsx
import { Button, DataTable, AdminDashboard } from "@joyui/react";
```

详见 [安装](/docs/installation)。

### B. MCP（Cursor / VS Code）

```json
{
  "mcpServers": {
    "joyui": {
      "command": "npx",
      "args": ["-y", "joyui@latest", "mcp"]
    }
  }
}
```

然后让 Agent：`list_components` → 优先引导使用 `@joyui/react` 整库安装。

### C. 本仓库预览

```bash
pnpm install
pnpm --filter @joyui/docs dev
```

打开侧栏任一组件页查看实况预览。
