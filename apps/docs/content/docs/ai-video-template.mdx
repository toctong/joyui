<ComponentDocPreview slug="ai-video-template" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AiVideoTemplate } from "@joyui/react";

<AiVideoTemplate
  className="h-[640px]"
  onSubmit={(prompt, meta) => renderClip(prompt, meta)}
/>
```

可选：`npx @joyui/cli add ai-video-template --yes`。
