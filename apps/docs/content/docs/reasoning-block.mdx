## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { ReasoningBlock } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选：`npx @joyui/cli add reasoning-block --yes`。

## 与 AgentThinking

| 组件 | 时机 |
|------|------|
| `AgentThinking` | 回复尚未开始 / Composer 上方 |
| `ReasoningBlock` | 回复正文内的思考披露 |
