可组合侧栏壳：`Sidebar` + `SidebarHeader` / `Content` / `Footer` + `SidebarItem`。  
支持纵向与 **horizontal 顶栏**；另提供完整仪表盘模板 `DashboardSidebar`。

<ComponentDocPreview slug="sidebar" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import {
  Sidebar,
  SidebarBrand,
  SidebarCollapseButton,
  SidebarContent,
  SidebarFooter,
  SidebarHeader,
  SidebarItem,
  SidebarNav,
  SidebarSection,
} from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。

## 纵向形态

浮动卡片、贴边、图标栏、分组导航。点击项可切换选中态；floating / grouped 可折叠。

## 横向顶栏

`variant="horizontal"`：品牌在左、导航横排、操作在右。

```tsx
<Sidebar variant="horizontal">
  <SidebarHeader>
    <SidebarBrand icon={RiSparklingLine} label="JoyUI" />
  </SidebarHeader>
  <SidebarContent>
    <SidebarNav items={nav} selected={selected} onSelect={setSelected} />
  </SidebarContent>
  <SidebarFooter>
    <SidebarItem icon={RiSettings4Line} label="设置" />
  </SidebarFooter>
</Sidebar>
```


## 基础用法

```tsx
import { useState } from "react";
import {
  Sidebar,
  SidebarBrand,
  SidebarCollapseButton,
  SidebarContent,
  SidebarFooter,
  SidebarHeader,
  SidebarItem,
  SidebarNav,
} from "@joyui/react";
import { RiHomeLine, RiSettings4Line, RiSparklingLine } from "@remixicon/react";

export function Example() {
  const [selected, setSelected] = useState("home");
  return (
    <Sidebar variant="floating" className="h-[440px]">
      <SidebarHeader>
        <SidebarBrand icon={RiSparklingLine} label="JoyUI" />
        <SidebarCollapseButton />
      </SidebarHeader>
      <SidebarContent>
        <SidebarNav
          items={[
            { key: "home", label: "概览", icon: RiHomeLine, badge: 3 },
          ]}
          selected={selected}
          onSelect={setSelected}
        />
      </SidebarContent>
      <SidebarFooter>
        <SidebarItem icon={RiSettings4Line} label="设置" />
      </SidebarFooter>
    </Sidebar>
  );
}
```

## variant

| 值 | 说明 |
|----|------|
| `floating` | 圆角卡片 + 阴影（默认） |
| `inset` | 贴边，右侧分隔线 |
| `rail` | 60px 图标栏（默认折叠） |
| `horizontal` | 顶栏横向导航 |

折叠时 floating 会收成 rail 宽度；inset 保持贴边样式只收窄。`horizontal` 忽略折叠。
