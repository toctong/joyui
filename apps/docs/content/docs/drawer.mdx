一套抽屉家族：任意边滑入的面板；编辑表单用粘性页眉 + 滚动正文 + 取消/保存页脚变体。API 各自独立、安装按 slug。

## 基础

从任意边滑入的面板；`start` / `end` 跟随阅读方向。

<ComponentDocPreview slug="drawer" />

```bash
pnpm add @joyui/react
```

```tsx
import { Drawer, DrawerBody, DrawerFooter, DrawerHeader } from "@joyui/react";
```

主题 CSS 已内置：`@import "@joyui/react/styles.css"`。可选：`npx @joyui/cli add drawer --yes`。
