一套树视图家族：基础 TreeView 管理展开 / 选择；需要资源管理器外壳与文件图标预设时换下方变体。

## 基础树

React Aria 管理键盘与选择；提供稳定 `id` 与 `aria-label`。

<ComponentDocPreview slug="tree-view" />

```bash
npx @joyui/cli add tree-view --yes
```

### 尺寸

`sm`（32px）· `md`（36px）。

<DemoFrame
  fileName="tree-view-sizes.tsx"
  code={`import { TreeView, TreeViewItem } from "@/components/base/tree-view/tree-view";

<>
  <TreeView aria-label="小" size="sm" defaultExpandedKeys={["src"]}>
    <TreeViewItem id="src" label="src">
      <TreeViewItem id="a" label="button.tsx" />
    </TreeViewItem>
  </TreeView>
  <TreeView aria-label="中" size="md" defaultExpandedKeys={["src"]}>
    <TreeViewItem id="src" label="src">
      <TreeViewItem id="a" label="button.tsx" />
    </TreeViewItem>
  </TreeView>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <TreeViewSizePreview />
</DemoFrame>

### 无引导线

`showGuides={false}` 隐藏连接干与弯枝。

<DemoFrame
  fileName="tree-view-guides.tsx"
  code={`import { TreeView, TreeViewItem } from "@/components/base/tree-view/tree-view";

<TreeView aria-label="文档" showGuides={false} defaultExpandedKeys={["docs"]}>
  <TreeViewItem id="docs" label="docs">
    <TreeViewItem id="intro" label="intro.mdx" />
  </TreeViewItem>
</TreeView>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-secondary-default p-8"
