下划线选项卡适合页面分区；胶囊适合工具栏视图切换。下方是**同一个** Tabs 家族的不同配置。

<ComponentDocPreview slug="tabs" />

## 安装

```bash
npx @joyui/cli add tabs --yes
```

或通过 JoyUI MCP / CLI 安装。

## 图标与计数

`Tab` 支持 `icon` 与 `count`，用于文件 / 成员等带数量的分区。

<DemoFrame
  fileName="tabs-count.tsx"
  code={`import { RiFolder3Line, RiSettings3Line, RiTeamLine } from "@remixicon/react";
import { Tab, TabList, TabPanel, Tabs } from "@/components/base/tabs/tabs";

<Tabs defaultSelectedKey="files">
  <TabList aria-label="工作区">
    <Tab id="files" icon={RiFolder3Line} count={24}>文件</Tab>
    <Tab id="members" icon={RiTeamLine} count={8}>成员</Tab>
    <Tab id="settings" icon={RiSettings3Line}>设置</Tab>
  </TabList>
  <TabPanel id="files">项目文件与共享链接。</TabPanel>
</Tabs>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <TabsCountPreview />
</DemoFrame>

## 应用场景

设置页分区：通用 / 账单（带计数）/ 安全。

<DemoFrame
  fileName="tabs-settings.tsx"
  code={`import { Tab, TabList, TabPanel, Tabs } from "@/components/base/tabs/tabs";

<Tabs defaultSelectedKey="general">
  <TabList aria-label="设置分区">
    <Tab id="general">通用</Tab>
    <Tab id="billing" count={2}>账单</Tab>
    <Tab id="security">安全</Tab>
  </TabList>
  <TabPanel id="general">语言、时区与外观。</TabPanel>
</Tabs>`}
