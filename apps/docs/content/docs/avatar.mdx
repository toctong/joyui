头像家族：单个 `Avatar`，以及协作场景的 `AvatarGroup`。

## 头像

图片或首字母头像，多种尺寸与色调。

<ComponentDocPreview slug="avatar" />

## 安装

```bash
npx @joyui/cli add avatar --yes
```

或通过 JoyUI MCP / CLI 安装。
