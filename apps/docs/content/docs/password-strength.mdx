Bencho Password strength：轻量启发式评分，亦可传入受控 `level`。

<ComponentDocPreview slug="password-strength" />

## 安装

```bash
npx @joyui/cli add password-strength --yes
```

```tsx
import { Input, PasswordStrength } from "@joyui/react";

<>
  <Input type="password" label="密码" value={pwd} onChange={setPwd} />
  <PasswordStrength value={pwd} />
</>
```
