注册 / 改密表单旁的强度提示。可传原始 `value` 本地评分，或直接 `level`。

<ComponentDocPreview slug="password-strength" />

## 安装

```bash
npx @joyui/cli add password-strength --yes
```

## 实时评分

与密码 Input 联动。

<DemoFrame
  fileName="password-strength-live.tsx"
  code={`import { useState } from "react";
import { Input } from "@/components/base/input/input";
import { PasswordStrength } from "@/components/base/password-strength/password-strength";

function Example() {
  const [value, setValue] = useState("Joy");
  return (
    <>
      <Input label="密码" type="password" value={value} onChange={setValue} />
      <PasswordStrength value={value} />
    </>
  );
}`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <PasswordStrengthLivePreview />
</DemoFrame>
