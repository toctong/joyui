单线、双线与填充三种 `variant`；可传入子节点作为中间文案或操作。

<ComponentDocPreview slug="divider" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { Divider } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add divider --yes`。


## 变体

`single` · `double` · `fill`。

## 带内容

通过 `children` 与 `align` 放置文案或按钮。

<DemoFrame
  fileName="divider-content.tsx"
