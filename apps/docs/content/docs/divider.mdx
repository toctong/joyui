单线、双线与填充三种 `variant`；可传入子节点作为中间文案或操作。

<ComponentDocPreview slug="divider" />

## 安装

```bash
npx @joyui/cli add divider --yes
```

或通过 JoyUI MCP / CLI 安装。

## 变体

`single` · `double` · `fill`。

<DemoFrame
  fileName="divider-variants.tsx"
  code={`import { Divider } from "@/components/base/divider/divider";

<>
  <Divider variant="single" />
  <Divider variant="double" />
  <Divider variant="fill" />
</>`}

</DemoFrame>

## 带内容

通过 `children` 与 `align` 放置文案或按钮。

<DemoFrame
  fileName="divider-content.tsx"
  code={`import { Divider } from "@/components/base/divider/divider";
import { Button } from "@/components/base/buttons/button";

<>
  <Divider variant="single" align="center">或</Divider>
  <Divider variant="single" align="start">更多选项</Divider>
  <Divider variant="fill" align="center">
    <Button variant="ghost" size="xs">展开全部</Button>
  </Divider>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <DividerContentPreview />
</DemoFrame>
