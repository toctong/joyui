长文、条款与面板阅读进度。`target` 指向可滚动元素。

<ComponentDocPreview slug="scroll-progress" />

## 安装

```bash
npx @joyui/cli add scroll-progress --yes
```

## 绑定容器

传入滚动容器 `ref`；`height` 控制条高。

<DemoFrame
  fileName="scroll-progress-target.tsx"
  code={`import { useRef } from "react";
import { ScrollProgress } from "@/components/base/scroll-progress/scroll-progress";

function Example() {
  const ref = useRef(null);
  return (
    <div>
      <ScrollProgress target={ref} height={3} />
      <div ref={ref} className="max-h-48 overflow-y-auto">…</div>
    </div>
  );
}`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"

</DemoFrame>
