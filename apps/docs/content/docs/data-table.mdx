业务列表请用 **`DataTable`**（传入 `data` / `columns` / `getRowId`）。  
`DataTableExample` 仅是营销演示，不要当生产组件。

<ComponentDocPreview slug="data-table" />

## 安装

```bash
npx @joyui/cli add data-table --yes
```

## 尺寸

`sm` · `md`，与基础 `Table` 行高一致。

<DemoFrame
  fileName="data-table-sizes.tsx"
  code={`import { DataTable } from "@/components/application/data-table/data-table-view";

<DataTable
  aria-label="转存表"
  size="sm"
  pageSize={3}
  data={rows}
  columns={columns}
  getRowId={(row) => row.id}
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <DataTableSizePreview />
</DemoFrame>

## 空状态

无数据时渲染 `emptyState`（默认文案可换）。

<DemoFrame
  fileName="data-table-empty.tsx"
  code={`<DataTable
  aria-label="空转存表"
  data={[]}
  columns={columns}
  getRowId={(row) => row.id}
  emptyState="暂无转存任务"
/>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <DataTableEmptyPreview />
</DemoFrame>
