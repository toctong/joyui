## 安装

```bash
npx @joyui/cli add carousel --yes
```

或通过 JoyUI MCP / CLI 安装。

## 应用场景

营销横幅、图库、仪表盘卡片组。`autoplay` + `loop` 适合无人值守展示；`align="center"` 可露出邻卡。
