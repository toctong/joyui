设置摘要、订单明细与只读资料。可用 `DescriptionItem` 快捷配对。

<ComponentDocPreview slug="description-list" />

## 安装

```bash
npx @joyui/cli add description-list --yes
```

## 列数

`columns={1|2}`；双列在 `sm+` 折成两栏。

<DemoFrame
  fileName="description-list-columns.tsx"
  code={`import { DescriptionItem, DescriptionList } from "@/components/base/description-list/description-list";

<>
  <DescriptionList columns={1}>
    <DescriptionItem term="计划">Pro</DescriptionItem>
  </DescriptionList>
  <DescriptionList columns={2}>
    <DescriptionItem term="区域">亚太</DescriptionItem>
    <DescriptionItem term="状态">活跃</DescriptionItem>
  </DescriptionList>
</>`}
