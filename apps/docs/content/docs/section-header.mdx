卡片或页面内的分区标题。`level` 映射为 h2–h4。

<ComponentDocPreview slug="section-header" />

## 安装

```bash
npx @joyui/cli add section-header --yes
```

## 标题级别

`2` · `3` · `4`。

<DemoFrame
  fileName="section-header-levels.tsx"
