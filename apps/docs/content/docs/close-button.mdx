圆形 ✕，用于关闭紧凑表面、公告、吐司、模态框和抽屉。每个尺寸用自己的笔画画字形——`2xs` 为 1.6px，`xs` / `sm` 为 2px，`md` 为 2.5px——权重保持像素真实，而不是缩放同一图标。

通过 `size` 切换款式；下面预览是**同一个** `CloseButton` 的四种配置。

<ComponentDocPreview slug="close-button" />

## 安装

```bash
npx joyui add close-button --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸

四种尺寸由 `size` 控制：16、20、24、32 像素。控件没有可见文字，请始终传入 `aria-label`。

<DemoFrame
  fileName="close-button-sizes.tsx"
  code={`import { CloseButton } from "@/components/base/buttons/close-button";

<div className="flex items-center gap-6">
  <CloseButton size="2xs" aria-label="Close" /> {/* 16px · 1.6px stroke */}
  <CloseButton size="xs" aria-label="Close" />  {/* 20px · 2px stroke */}
  <CloseButton size="sm" aria-label="Close" />  {/* 24px · 2px stroke */}
  <CloseButton size="md" aria-label="Close" />  {/* 32px · 2.5px stroke */}
</div>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <CloseButtonSizePreview />
</DemoFrame>

```tsx
<CloseButton size="2xs" aria-label="Close" /> {/* 16px, 1.6px stroke */}
<CloseButton size="xs" aria-label="Close" />  {/* 20px, 2px stroke */}
<CloseButton size="sm" aria-label="Close" />  {/* 24px, 2px stroke */}
<CloseButton size="md" aria-label="Close" />  {/* 32px, 2.5px stroke */}
```
