计数与状态胶囊。完整强调色矩阵优先用 `Chip`；`Badge` 适合侧栏计数与紧凑状态。

<ComponentDocPreview slug="badge" />

## 安装

```bash
npx @joyui/cli add badge --yes
```

或通过 JoyUI MCP / CLI 安装。

## 颜色

通过 `color` 切换语义色。

<DemoFrame
  fileName="badge-colors.tsx"
  code={`import { Badge } from "@/components/base/badges/badge";

<>
  <Badge color="primary">12</Badge>
  <Badge color="neutral">3</Badge>
  <Badge color="success">OK</Badge>
  <Badge color="warning">2</Badge>
  <Badge color="error">99+</Badge>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <BadgeColorPreview />
</DemoFrame>

## 应用场景

侧栏导航未读计数：选中行可用浅色徽章叠在主色底上。
