受控分页：`page` + `totalPages` + `onChange`。下方是**同一个** `Pagination` 的不同配置。

<ComponentDocPreview slug="pagination" />

## 安装

```bash
npx @joyui/cli add pagination --yes
```

或通过 JoyUI MCP / CLI 安装。

## 相邻页数

`siblingCount` 控制当前页两侧展示的页码数量。

<DemoFrame
  fileName="pagination-siblings.tsx"
  code={`import { Pagination } from "@/components/base/pagination/pagination";

<>
  <Pagination page={5} totalPages={20} onChange={() => {}} siblingCount={1} previousLabel="上一页" nextLabel="下一页" />
  <Pagination page={5} totalPages={20} onChange={() => {}} siblingCount={2} previousLabel="上一页" nextLabel="下一页" />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <PaginationSiblingPreview />
</DemoFrame>

## 应用场景

表格页脚：转存记录列表底部翻页。
