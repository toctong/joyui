拟物拨动开关。下方是**同一个** `Switch` 的不同配置；设置行可用 `SwitchCard`。

<ComponentDocPreview slug="switch" />

## 安装

```bash
npx @joyui/cli add switch --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸

`sm` · `md` · `lg`。

<DemoFrame
  fileName="switch-sizes.tsx"

## 形状

`shape="pill"`（默认）· `rectangle`；支持 `isDisabled`。

<DemoFrame
  fileName="switch-shapes.tsx"
  code={`import { Switch } from "@/components/base/switch/switch";

<>
  <Switch shape="pill" defaultSelected>胶囊</Switch>
  <Switch shape="rectangle" defaultSelected>直角</Switch>
  <Switch isDisabled>禁用</Switch>
</>`}
