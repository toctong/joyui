用 `ratio`（数字，默认 `16/9`）锁定子内容宽高比，避免布局跳动。

<ComponentDocPreview slug="aspect-ratio" />

## 安装

```bash
npx @joyui/cli add aspect-ratio --yes
```

或通过 JoyUI MCP / CLI 安装。

## 常见比例

传入 `16/9`、`1`、`4/3`、`2/3` 等数值。

<DemoFrame
  fileName="aspect-ratio-presets.tsx"
  code={`import { AspectRatio } from "@/components/base/aspect-ratio/aspect-ratio";

<>
  <AspectRatio ratio={16 / 9}>16:9</AspectRatio>
  <AspectRatio ratio={1}>1:1</AspectRatio>
  <AspectRatio ratio={4 / 3}>4:3</AspectRatio>
  <AspectRatio ratio={2 / 3}>2:3</AspectRatio>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <AspectRatioPresetPreview />
</DemoFrame>

## 应用场景

媒体卡片封面：锁定 16:9 占位。
