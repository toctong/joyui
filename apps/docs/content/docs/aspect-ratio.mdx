<ComponentDocPreview slug="aspect-ratio" />

## 安装

```bash
npx @joyui/cli add aspect-ratio --yes
```

```tsx
import { AspectRatio } from "@joyui/react";

<AspectRatio ratio={16 / 9} className="rounded-2xl bg-background-secondary-default">
  <img src="/cover.jpg" alt="" className="size-full object-cover" />
</AspectRatio>
```
