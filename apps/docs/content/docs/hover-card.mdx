短延迟打开，移入面板可继续阅读。下方是**同一个** `HoverCard` 的不同配置；资料场景可直接用 `HoverCardProfile`。

## 基础

<ComponentDocPreview slug="hover-card" />

```bash
npx @joyui/cli add hover-card --yes
```

### 延迟

`openDelay` / `closeDelay`（毫秒）控制打开与关闭时机。

<DemoFrame
  fileName="hover-card-delay.tsx"
  code={`import { Avatar } from "@/components/base/avatar/avatar";
import { HoverCard } from "@/components/base/hover-card/hover-card";

<>
  <HoverCard openDelay={0} closeDelay={80} content={<p>立即打开</p>}>
    <Avatar initials="快" color="blue" />
  </HoverCard>
  <HoverCard openDelay={400} closeDelay={200} content={<p>较慢打开</p>}>
    <Avatar initials="慢" color="lime" />
  </HoverCard>
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <HoverCardDelayPreview />
</DemoFrame>

### 应用场景

列表行头像悬停：面板内展示姓名与角色。

<DemoFrame
  fileName="hover-card-profile-scenario.tsx"
