日志、评论与活动流时间戳。基于 `Intl.RelativeTimeFormat`。

<ComponentDocPreview slug="relative-time" />

## 安装

```bash
npx @joyui/cli add relative-time --yes
```

## 语言环境

`locale` 切换格式；`showAbsoluteTitle` 在悬停 title 显示绝对时间。

<DemoFrame
  fileName="relative-time-locale.tsx"

</>`}
