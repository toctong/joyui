## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { ImageGeneration } from "@joyui/react";
// 或
import { ImageGeneration } from "@joyui/react/ai";
```

## 用法

```tsx
<ImageGeneration
  aspect="1:1"
  models={[
    { id: "fable-5", name: "Fable 5" },
    { id: "fable-pro", name: "Fable Pro" },
  ]}
  onSubmit={(prompt, meta) => {
    // meta: { aspect, styleId, modelId }
    // 调用你的生图接口，再更新 messages / gallery
  }}
/>
```

自定义消息与画廊：

```tsx
<ImageGeneration
  messages={[
    { id: "u1", role: "user", text: "一只在月球上的猫" },
    {
      id: "a1",
      role: "assistant",
      resultLabel: "生成图像",
      asset: { id: "img1", src: "/demo/cat.png", alt: "猫", ratio: 1 },
    },
  ]}
  gallery={[{ id: "img1", src: "/demo/cat.png", alt: "猫", ratio: 1 }]}
/>
```

扩展输入与侧栏：

```tsx
<ImageGeneration
  sidePanel={false}
  showComposerFooter={false}
  composerProps={{ showMic: false, showAttach: false }}
  headerActions={<YourMenu />}
  renderComposer={({ value, setValue, submit, busy }) => (
    <YourPromptBar value={value} onChange={setValue} onSubmit={submit} busy={busy} />
  )}
/>
```
