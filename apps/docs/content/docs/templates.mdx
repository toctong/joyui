整页装配，对标 shadcn blocks / Figma Community kits：侧栏、KPI、图表、对话与鉴权已串好，可 `cli add` 进业务仓库。画廊卡片会**新开窗口**打开全屏预览（`/templates/preview/<slug>`）。

## 可安装（OSS）

| 模板 | 说明 | 安装 |
|------|------|------|
| [后台管理](/docs/admin-dashboard) | 侧栏 + KPI + 图表 + 表 | `npx @joyui/cli add admin-dashboard --yes` |
| [AI 对话](/docs/ai-chat-template) | `AiChat` 全页壳 | `npx @joyui/cli add ai-chat-template --yes` |
| [AI 助手](/docs/ai-assistant-template) | 多会话侧栏 + 对话（vercel/chatbot 风格） | `npx @joyui/cli add ai-assistant-template --yes` |
| [图像生成](/docs/ai-image-template) | Creative 生图工作室 | `npx @joyui/cli add ai-image-template --yes` |
| [视频生成](/docs/ai-video-template) | Motion 视频工作室 | `npx @joyui/cli add ai-video-template --yes` |
| [AI Playground](/docs/ai-playground-template) | 调参轨 + 提示 / 输出 | `npx @joyui/cli add ai-playground-template --yes` |
| [AI Agent](/docs/ai-agent-template) | 推理 · 工具 · 任务轨迹 | `npx @joyui/cli add ai-agent-template --yes` |
| [登录页](/docs/auth-template) | `AuthCard` 媒体分栏 | `npx @joyui/cli add auth-template --yes` |
| [工作台](/docs/workspace-template) | 档案卡 + 动态流 + 侧栏 | `npx @joyui/cli add workspace-template --yes` |

```bash
pnpm add @joyui/react
```

```tsx
import {
  AdminDashboard,
  AiChatTemplate,
  AiAssistantTemplate,
  AiImageTemplate,
  AiVideoTemplate,
  AiPlaygroundTemplate,
  AiAgentTemplate,
  AuthTemplate,
  WorkspaceTemplate,
} from "@joyui/react";
```

主题 CSS：`@import "@joyui/react/styles.css"`。

## Pro 垂直预览

Finance / marketing / healthcare 等完整垂直页仍为 Pro 嵌入预览（非开源组件）。Healthcare 是**行业模板**，与通用 [档案卡片](/docs/profile-cards) 无关。
