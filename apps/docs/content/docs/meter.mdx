配额、完成度与健康度展示。`tone` 控制语义色，`size` 控制轨高。

<ComponentDocPreview slug="meter" />

## 安装

```bash
npx @joyui/cli add meter --yes
```

## 色调

`accent` · `success` · `warning` · `error`。

<DemoFrame
  fileName="meter-tones.tsx"
  code={`import { Meter } from "@/components/base/meter/meter";

<>
  <Meter label="品牌" value={72} tone="accent" />
  <Meter label="成功" value={88} tone="success" />
  <Meter label="警告" value={54} tone="warning" />
  <Meter label="错误" value={28} tone="error" />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>

</DemoFrame>

## 尺寸与说明
