一套模态家族：居中对话框；移动端友好的底部 sheet 另用变体。危险确认用 `AlertDialog`（不可点遮罩关闭）。API 各自独立、安装按 slug。

## 基础

遮罩上的居中对话框。支持 Trigger 非受控与 `isOpen` 受控。

<ComponentDocPreview slug="modal" />

```bash
npx @joyui/cli add modal --yes
```

### Trigger 模式（非受控）

按钮打开，内部 `{({ close }) => …}` 关窗：

```tsx
import { Button, Modal, ModalBody, ModalFooter, ModalHeader, ModalTrigger } from "@joyui/react";

<ModalTrigger>
  <Button>Invite</Button>
  <Modal>
    {({ close }) => (
      <>
        <ModalHeader title="Invite teammates" description="They get a join link." />
        <ModalBody>Form fields</ModalBody>
        <ModalFooter>
          <Button variant="secondary" onClick={close}>Cancel</Button>
          <Button onClick={close}>Send</Button>
        </ModalFooter>
      </>
    )}
  </Modal>
</ModalTrigger>
```

### 受控模式（`isOpen`）

编辑弹窗、命令式打开用自己的 state，**不要**包 `ModalTrigger`：

```tsx
import { useState } from "react";
import { Button, Modal, ModalBody, ModalFooter, ModalHeader } from "@joyui/react";

export function EditTaskDialog() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button onClick={() => setOpen(true)}>Edit</Button>
      <Modal isOpen={open} onOpenChange={setOpen}>
        {({ close }) => (
          <>
            <ModalHeader title="Edit task" />
            <ModalBody>…</ModalBody>
            <ModalFooter>
              <Button variant="secondary" onClick={close}>Cancel</Button>
              <Button onClick={close}>Save</Button>
            </ModalFooter>
          </>
        )}
      </Modal>
    </>
  );
}
```

`Modal` 继承 React Aria `ModalOverlay` 的 `isOpen` / `onOpenChange` / `isDismissable`。

### 何时用 AlertDialog

- 删除、不可逆操作
- 需要 `role="alertdialog"`、默认不可点遮罩关闭
- 焦点落在 Cancel

普通表单 / 详情用 `Modal`。
