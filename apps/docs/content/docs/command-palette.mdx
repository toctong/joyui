可搜索的动作与目的地列表。默认 ⌘K / Ctrl+K 打开；也可受控 `isOpen`。

<ComponentDocPreview slug="command-palette" />

## 安装

```bash
npx @joyui/cli add command-palette --yes
```

## 按钮触发

关闭全局快捷键（`shortcut={false}`），用按钮受控打开。

<DemoFrame
  fileName="command-palette-trigger.tsx"
  code={`import { useState } from "react";
import { RiHome5Line } from "@remixicon/react";
import { Button } from "@/components/base/buttons/button";
import { CommandPalette, CommandPaletteItem, CommandPaletteSection } from "@/components/base/command-palette/command-palette";

function Example() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button onClick={() => setOpen(true)}>打开命令面板</Button>
      <CommandPalette isOpen={open} onOpenChange={setOpen} shortcut={false} placeholder="搜索…">
        <CommandPaletteSection title="导航">
          <CommandPaletteItem id="home" icon={RiHome5Line}>仪表盘</CommandPaletteItem>
        </CommandPaletteSection>
      </CommandPalette>
    </>
  );
}`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <CommandPaletteTriggerPreview />
</DemoFrame>

## 空状态

`emptyState` 自定义无匹配文案；`footer={false}` 可隐藏底部快捷键提示。

<DemoFrame
  fileName="command-palette-empty.tsx"
  code={`import { CommandPalette, CommandPaletteItem } from "@/components/base/command-palette/command-palette";

<CommandPalette isOpen emptyState="没有匹配结果" footer={false} filter={null}>
  <CommandPaletteItem id="x">隐藏项</CommandPaletteItem>
</CommandPalette>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-secondary-default p-8"
>
  <CommandPaletteEmptyPreview />
</DemoFrame>
