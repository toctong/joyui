状态与增量标签。`color` 覆盖语义色矩阵；`variant` 控制字号与内边距。

<ComponentDocPreview slug="chip" />

## 安装

```bash
npx @joyui/cli add chip --yes
```

或通过 JoyUI MCP / CLI 安装。

## 颜色

`orange` · `lime` · `rose` · `yellow` · `cyan` · `blue` · `purple` · `neutral` · `gray` · `soft`。

## 变体

`bold`（状态）· `subtle`（价格 / 增量）· `caption`（角色标签）。

  fileName="chip-variants.tsx"
