<ComponentDocPreview slug="number-field" />

## 安装

```bash
npx @joyui/cli add number-field --yes
```

或通过 JoyUI MCP / CLI 安装。

## 尺寸

`size="medium" | "small"`。

## 格式与步进器

`formatOptions`（货币 / 百分比）；`hideSteppers` 隐藏加减按钮。

<DemoFrame
  fileName="number-field-format.tsx"
  code={`import { NumberField } from "@/components/base/number-field/number-field";

<>
  <NumberField label="价格" defaultValue={49} formatOptions={{ style: "currency", currency: "CNY" }} />
  <NumberField label="税率" defaultValue={0.08} step={0.01} formatOptions={{ style: "percent" }} />
  <NumberField label="无步进器" defaultValue={12} hideSteppers />
</>`}
  canvasClassName="min-h-40 items-center justify-center bg-background-primary-default p-8"
>
  <NumberFieldFormatPreview />
</DemoFrame>
