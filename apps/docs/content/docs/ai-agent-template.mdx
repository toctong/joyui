## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { AiAgentTemplate } from "@joyui/react";

<AiAgentTemplate
  className="h-[640px]"
  messages={messages}
  busy={busy}
  onSubmit={(prompt) => runAgent(prompt)}
  panel={<YourTrace />}
/>
```

可选：`npx @joyui/cli add ai-agent-template --yes`。
