beUI / Watermelon 常见的协作头像堆叠：超出 `max` 显示 `+N`。

<ComponentDocPreview slug="avatar-group" />

## 安装

```bash
npx @joyui/cli add avatar-group --yes
```

```tsx
import { Avatar, AvatarGroup } from "@joyui/react";

<AvatarGroup max={3}>
  <Avatar initials="A" color="blue" />
  <Avatar initials="B" color="lime" />
  <Avatar initials="C" color="pink" />
  <Avatar initials="D" />
</AvatarGroup>
```
