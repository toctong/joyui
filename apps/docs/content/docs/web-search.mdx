<ComponentDocPreview slug="web-search" />

## 安装

```bash
pnpm add @joyui/react
```

```tsx
import { WebSearch } from "@joyui/react";
```

主题与组件 CSS 已内置：`@import "@joyui/react/styles.css"`。可选源码拷贝：`npx @joyui/cli add web-search --yes`。

## 自定义步骤

```tsx
import { WebSearch, type WebSearchStep } from "@joyui/react";

const steps: WebSearchStep[] = [
  {
    id: "q1",
    kind: "query",
    label: "搜索组件库定价",
    resultLabel: "3 个结果",
    sources: [
      { id: "gh", label: "GitHub", color: "#24292F", mark: "⌘" },
      { id: "npm", label: "npm", color: "#CB3837", mark: "n" },
    ],
  },
  { id: "q2", kind: "read", label: "阅读定价页与 README" },
];

<WebSearch steps={steps} />
```

`kind`：`query`（灯泡 + 来源）、`x` / `reddit`（站点标记）、`read`（阅读）。组件内置重播按钮，便于演示。
