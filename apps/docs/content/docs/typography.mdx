字号、字重、行高打包在同一工具类里，例如 `text-title-2-medium`。

<FoundationTypeDemo />

## 原则

- 标题：`text-display-*` / `text-title-*` / `text-headline-*`
- 正文：`text-body-1-regular` / `text-body-1-medium`
- 说明：`text-caption-1-*` / `text-label-1-*`
- 禁止：`text-sm font-medium` 手拼字阶
